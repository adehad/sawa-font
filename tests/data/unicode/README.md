# Unicode test data

`BidiCharacterTest.txt.gz` is Unicode 15.1.0's bidi conformance test, gzipped
without changes (its Unicode copyright header is intact inside), from
https://www.unicode.org/Public/15.1.0/ucd/BidiCharacterTest.txt. Its version
must match the stdlib `unicodedata` that `sawa_tools.report.bidi` uses.
Terms of use: https://www.unicode.org/terms_of_use.html
